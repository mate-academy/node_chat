# 💬 RoomTalk

Простий realtime-чат із кімнатами. Введи ім'я, обери або створи кімнату — і спілкуйся з іншими користувачами без перезавантаження сторінки.

[![GitHub](https://img.shields.io/badge/GitHub-Переглянути_код-1F4B43?style=for-the-badge&logo=github)](https://github.com/Inna-code10/node_chat/tree/develop)

---

## 📋 Що вміє застосунок

- **Вхід за іменем** — вводиш username, він зберігається в `localStorage`, і при наступному відкритті сторінки тебе одразу впізнають.
- **Кімнати** — можна створювати нові кімнати, перейменовувати їх, видаляти та переключатись між ними.
- **Повідомлення з автором і часом** — кожне повідомлення показує, хто і коли його написав.
- **Історія повідомлень** — новий учасник кімнати одразу бачить усі попередні повідомлення в ній.
- **Індикатор "хтось друкує…"** — видно, коли співрозмовник набирає текст.
- **Автоматичний reconnect** — якщо з'єднання розірветься (мережа моргнула, сервер перезапустився), клієнт сам перепідключається, без ручного оновлення сторінки.
- **Валідація на сервері** — перевірка порожніх повідомлень, довжини тексту, унікальності username.
- **Персистентність** — повідомлення й кімнати зберігаються на сервері у файл і не зникають при перезапуску.

## 🛠️ Технології

### Backend (`server/node_chat`)
- **Node.js** — середовище виконання
- **WebSocket (`ws`)** — realtime-зв'язок клієнта й сервера
- **Файлове сховище (JSON)** — персистентність кімнат і повідомлень без окремої бази даних
- **ESLint + Prettier** — лінтинг і форматування коду

### Frontend (`client/video-nodejs_realtime-chat-client`)
- **React** — побудова інтерфейсу
- **Create React App (`react-scripts`)** — збірка й dev-сервер
- **WebSocket API** (нативний браузерний) — з'єднання з backend через кастомний React-хук `useWebSocket`
- **CSS** — власні стилі без сторонніх UI-бібліотек

### Метод зв'язку клієнта й сервера

Клієнт і сервер спілкуються через **єдине WebSocket-з'єднання**, повідомлення передаються у форматі JSON з полем `type` (наприклад, `join`, `message`, `create_room`, `typing`). Сервер веде облік, хто в якій кімнаті перебуває, і розсилає повідомлення лише учасникам відповідної кімнати (`broadcastToRoom`).

## 🚀 Встановлення та запуск локально

### 1. Клонувати репозиторій

```bash
git clone https://github.com/Inna-code10/node_chat.git
cd node_chat
```

### 2. Запустити backend

```bash
cd server/node_chat
npm install
npm start
```

Сервер запуститься на `ws://localhost:5000`.

### 3. Запустити frontend (у новому терміналі)

```bash
cd client/video-nodejs_realtime-chat-client
npm install
npm start
```

Застосунок відкриється у браузері за адресою `http://localhost:3000`.

## 🧪 Як спробувати чат з кількома людьми

1. Переконайся, що backend і frontend запущені (кроки 2-3 вище).
2. Відкрий `http://localhost:3000` у кількох вкладках браузера — кожна вкладка симулює окремого користувача.
3. Або поділись адресою в тій самій локальній мережі з іншим пристроєм.
