# Node.js Chat Application

Повноцінний чат-застосунок, створений з використанням Node.js, Express та Socket.IO.

## Функціональність

### Користувачі
- ✅ Введення імені користувача
- ✅ Збереження імені в localStorage
- ✅ Відображення поточного користувача

### Повідомлення
- ✅ Відправка повідомлень з автором, часом та текстом
- ✅ Відображення історії повідомлень при вході в кімнату
- ✅ Різне оформлення для власних та чужих повідомлень
- ✅ Системні повідомлення (користувач приєднався/покинув кімнату)

### Кімнати
- ✅ Створення нових кімнат
- ✅ Перейменування існуючих кімнат
- ✅ Приєднання до кімнат
- ✅ Видалення кімнат (крім загальної)
- ✅ Відображення списку кімнат з кількістю користувачів та повідомлень
- ✅ Захист загальної кімнати від видалення

### Технічні особливості
- ✅ Real-time комунікація через WebSocket
- ✅ Автоматичне оновлення списку кімнат
- ✅ Обмеження історії повідомлень (останні 100)
- ✅ Адаптивний дизайн
- ✅ Сучасний UI з анімаціями

## Технології

- **Backend**: Node.js, Express.js
- **Real-time**: Socket.IO
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Стилізація**: CSS Grid, Flexbox, CSS Animations
- **Зберігання**: In-memory (Map та Set)

## Встановлення та запуск

### 1. Клонування репозиторію
```bash
git clone <your-forked-repo-url>
cd node_chat
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Запуск застосунку

#### Розробка (з автоматичним перезапуском)
```bash
npm run dev
```

#### Продакшн
```bash
npm start
```

### 4. Відкриття в браузері
Відкрийте [http://localhost:3000](http://localhost:3000) у вашому браузері.

## API Endpoints

### HTTP API
- `GET /api/rooms` - Отримати список всіх кімнат
- `GET /api/rooms/:roomName/messages` - Отримати повідомлення конкретної кімнати

### Socket.IO Events

#### Клієнт → Сервер
- `joinRoom` - Приєднатися до кімнати
- `sendMessage` - Відправити повідомлення
- `createRoom` - Створити нову кімнату
- `renameRoom` - Перейменувати кімнату
- `deleteRoom` - Видалити кімнату
- `getRooms` - Отримати список кімнат

#### Сервер → Клієнт
- `roomHistory` - Історія повідомлень кімнати
- `newMessage` - Нове повідомлення
- `userJoined` - Користувач приєднався до кімнати
- `userLeft` - Користувач покинув кімнату
- `roomCreated` - Кімната створена
- `roomRenamed` - Кімната перейменована
- `roomDeleted` - Кімната видалена
- `roomsList` - Оновлений список кімнат
- `error` - Помилка

## Використання

### 1. Вхід в чат
- Введіть своє ім'я користувача
- Натисніть "Join Chat"
- Ім'я збережеться в localStorage

### 2. Робота з кімнатами
- **Приєднання**: Клікніть на назву кімнати в списку
- **Створення**: Введіть назву нової кімнати та натисніть "Create Room"
- **Перейменування**: Натисніть "Rename" у поточній кімнаті
- **Видалення**: Натисніть "Delete" у поточній кімнаті

### 3. Відправка повідомлень
- Виберіть кімнату
- Введіть текст повідомлення
- Натисніть "Send" або Enter
